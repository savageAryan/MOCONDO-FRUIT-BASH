# MOCONDO FRUIT BASH! (pre-release 0.1)
Mocondo fruit bash is a Hackclub Mocondo Event Themed game,You are Trapped on an island called "MOCONDO" it's a magical island,with different talking animals some are friendly some not so much,You have to survive and escape to Human world

## ISTRUCTIONS TO PLAY:
## -HOW TO PLAY?
* PLAY THE GAME
[ Download Mocondo Fruit Bash on itch.io](https://savagearyan.itch.io/mocondofruitbash)

Currently available for **Windows only**.

If Windows Defender displays a security warning, you may need to select **More info → Run anyway** if you trust the build.
### -CONTROLS:
* Movement - WSAD
* Inventory(Open/Close) - E
* Hit/attack - LMB
* Plough use - RMB
* Eat/Heal - R
* Pause - ESCAPE
### You can do these in any order!
* Talk to chicken
* Talk to monkey
* learn to farm from chicken
* use axe on trees
* Talk to blob
* Fight Blob
* Talk to Capybra
* watch Capybara sleep and butterfly rest on it
* watch Capybare gets angry and moves butterfly fly away
* Go to capybara when it's sleeping
* You can go to the boat on the sand beach and use it but you will have to reopen the gam as it's supposed to be the ending but its incomplete and under development currently
* Collect fruits
* Use Tractor
* Sell/Buy at Workshop (currently you can only buy some items and sell some items, eg: you can sell fruit but can't buy them or you can buy tools can't sell them)
* Explore idea of gold econmoy(Incomplete)
* Watch Butterflies and Butterfly swarm
* Watch the dynamic lighting
* Watch the Day-night cycle
* Catch Chicken sleeping
* Let Blob kill you so you can see death screen
