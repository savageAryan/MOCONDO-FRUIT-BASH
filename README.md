# MOCONDO FRUIT BASH!
Mocondo fruit bash is a Hackclub Mocondo Event Themed game,You are Trapped on an island called "MOCONDO" it's a magical island,with different talking animals some are friendly some not so much,You have to survive and escape to Human world

## -HOW TO PLAY?
* Visit https://savagearyan.itch.io/mocondofruitbash ,click on Download to download the executable and run it (currently only for WINDOWS)
* If you Get windows security error Click run anyways
## -CONTROLS:
* Movement - WSAD
* Inventory(Open/Close) - E
* Hit/attack - LMB
* Plough use - RMB
* Eat/Heal - R
* Pause - ESCAPE
## ISTRUCTIONS TO PLAY:
### You can do these in any order!
* Talk to chicken
* Talk to monkey
* learn to farm from chicken
* use axe on trees
* Talk to blob
* Fight Blob
* Talk to Capybra
* Go to capybara when it's sleeping
* Collect fruits
* Use Tractor
* Sell/Buy at Workshop
* Watch Butterflies and Butterfly swarm
